# INK TIDE v2 / 墨潮

右側の粘る黒い液体と銀の繊維。左約40%の静けさを学習させ、
拍の直前の動き、上へ吸い上げられる糸、逆行して一滴へ戻る動きでその予測を破る。
パレットは深い黒、青灰、銀、右上の薄い暖色。色は線形 HDR で出力する。

## 振付

- **Kick:** エンベロープの立ち上がりで一度だけ発火。右側の弧に沿う力が液体を曲げ、
  正の力 → 負の反動 → 減衰と続く。符号を持つ応答は約1拍で収まり、流体には慣性が残る。
  弧の位置は拍番号に応じて3種類を使う。
- **Anticipation:** 直近3拍以内にキックがある場合、beat > 0.85 で次の拍を先取りする。
  先行する力はキックより弱く、1拍につき1回。無音の時計だけでは発火しない。
- **Tension:** 0.65秒の追従で画面内の `(0.72, 0.60)` へ引き寄せる。
  水平方向を強く縮める染料の移動で、厚みを増した細い縦糸になる。
  キャリアの速度は圧力投影するが、インクの厚みの移動には凝集を許す。
- **Drop:** 信号の立ち上がりから独立した9拍のイベントを開始する。
  0〜3拍は保存した約4拍分の実際の染料・材質座標を逆順に補間再生。
  3〜4拍はその模様を凝集先へ縮め、一つの濡れた滴へ収束する。
  4拍でその滴をシミュレーションへ戻し、2拍かけて左向きの曲がる噴流と細い染料帯を放つ。
  左の境界を開くのは4〜7拍、7〜9拍で静域を回復する。通常のキックはこのイベント中休止。
  噴出の0.15秒後から右側の補充を立ち上げ、0.8秒後に最大にする。
  補充は噴出から4秒で収まり、通常時の緩慢な補充へ戻る。拍ではなく秒で管理する。
- **Low:** 1.8秒で平滑化して粘性を少し増やす。Energy の低域変調も弧の力だけに作用する。
- **High:** 表面の細い反射光のみ。位置や明るさ全体を音量で振動させない。

逆行の前半は実際の履歴再生。最後の1拍の一滴への収束は演出的な座標圧縮と滴への移行であり、
物理シミュレーションを数学的に逆積分するものではない。
履歴がまだない起動直後にも、現在の染料から一滴へ収束できる。
通常時は微弱な漂流と緩慢な染料の補充だけで、静止に近い時間を保つ。

## マクロ

| マクロ | 役割 |
| --- | --- |
| Energy | キックの弧の力。low を最大 +0.22 加算 |
| Viscosity | 速度の拡散と抵抗。高いほど粘って早く落ち着く |
| Gloss | 高さ場の法線、タイトな銀の反射 |
| Stretch | 弧の伸びと噴流の太さ |
| Tension | 上昇・凝集の強さ |
| Warmth | 右上の淡い金色 |
| Calm | 通常時の左の静域と漂流の抑制。DROP はこの境界を越える |
| Reverse | 逆にたどる履歴の深さ。0でも一滴への収束と噴出は残る |

calm は強い粘性と小さい弧。surge は長い曲線と強い艶。
両方で DROP の履歴逆行を最大にする。

## 流体と表面

速度・染料・圧力は別々の HalfFloat ping-pong。
速度の semi-Lagrangian 移流、安定な近傍拡散、力の注入、
発散の計算、12回の Jacobi 圧力反復、圧力勾配の除去、染料の移流の順に進む。
各操作は専用シェーダーで、必要なテクスチャのみをバインドする。
補充に使う初期形状はリサイズ／再初期化時に一度だけ描き、以後はテクスチャ参照する。
染料は往復移流の誤差補正を近傍範囲で制限し、薄い曲線が霧へ拡散するのを抑える。
密度の弱い界面強調も使う。完全な自由表面・体積保存の液体ソルバーではなく、
非圧縮キャリア上のインクの厚みを扱う2Dモデル。

壁の法線方向の速度を減衰させるfree-slip境界を移流後・圧力投影後に適用し、
両方で速度の大きさを1.8以下に制限する。染料は壁へ滑らかに減衰し、
領域外では密度ゼロ。テクスチャ参照自体は半テクセル内へ制限する。
凝集の往復追跡には指数圧縮の正しい逆変換を使う。
移流・履歴再生とも密度0〜3、材質座標は領域内へ制限する。

材質座標は現在のUVからの変位として染料と移流する。
絶対UVをHalfFloatで保存する場合の小さな移動の丸めを避け、粒子と繊維を液体に貼り付ける。
逆再生でも同じ密度・変位のレイアウトを使い、一滴へ移行するときは変位も補間して戻す。
染料密度を高さとして低解像度で中央差分を求め、全解像度で勾配を補間して法線へ変換する。

狭いスペキュラー、帯状の環境反射、背景の微小な屈折で濡れた表面を作る。
表面に黒い実体を残し、繊維だけの煙にならないようにする。

## 停止経路の修正

- 時刻だけが同じでも frame または beats が進んでいれば、新しいライブフレームとして更新する。
  時刻・frame・beatsがすべて同じ再描画は進めない。
- Engine.load の64 × 36試験ターゲットは、シミュレーションの大きさを変えない。
  dt=0の試験描画・停止描画は、DROPやKickの立ち上がりを消費しない。
  同じ時刻の最初のdt>0フレームでも更新する。
- DROPは0.35未満まで解放するか、前フレームから0.15超の明確な上昇があると再発火する。
  旧処理では0.7の閾値を往復するだけで毎回dropAge=0になり、逆再生を永続させ得た。
  held envelope、通常の減衰、閾値付近の微小な揺れでは再発火しない。
- 粘性抵抗と圧力投影のあとにも残る緩慢な流れを追加した。
  密度と材質変位の両方が無音でも動き、Kickで曲がり、BUILDで凝集する。

通常の減衰するDROPでは、旧状態機械も4拍で逆再生を抜けていた。
提供されたChromeの完全停止を直接再現できていないため、上記をその録画の原因と断定はしない。

## 予算・ライフサイクル

- シミュレーションは1/4解像度、最大480 × 270。
  逆再生の解決と高さ勾配も同解像度。銀の反射・繊維・粒子のシェーディングは全解像度。
- 通常1ステップは流体16描画（12回の圧力反復）＋法線1回＋表面1回＝18描画。
  履歴コピーは約1/4拍に1回。逆再生中は流体と履歴を止め、履歴解決＋法線＋表面の3描画。
  一滴の再シードは噴出開始時だけ。
- 全解像度パスは染料と勾配の2テクスチャ参照。
  旧版は通常5参照、逆再生中10参照と繰り返し座標圧縮を行っていた。
  背景の微小な屈折は一階近似で、背景の再計算を避ける。
- 速度2・染料2・圧力2・発散1・初期染料1・逆再生染料1・勾配1・履歴17の計27ターゲット。
  最大480 × 270 RGBA16Fで約26.7 MiB／インスタンス。エンジン所有のターゲット等は含まない。
- dtは演出で最大100ms、流体で最大50ms。流体は1ステップ最大25ms、最大2サブステップ。
  60/90/120 Hzは1ステップ、24/30 Hzや停止復帰時は2。
  低FPSで流体の追跡時間を捨てても、逆再生イベントの進行を同じ50msで切り捨てない。
- 1542 × 867では流体386 × 217。通常18描画、約10.3Mテクスチャ参照／フレーム。
  2サブステップ時は34描画、約17.5M参照。履歴コピー・エンジンの仕上げは別。
  旧版3サブステップ時の73描画・約38.1M参照に対し、通常時の参照数は約73%少ない。
  これはシェーダー内の参照回数による概算であり、帯域量やGPU時間の測定ではない。
  90fpsの時間予算は11.1ms。M5 Maxでの達成と2窓60fpsは実測が必要。
- resizeと時刻の巻き戻しでは再シードして履歴を破棄する。
  disposeは全所有ターゲットと10パスのマテリアルを解放する。
  依存追加・エンジン側の変更は不要。

## 検証

npx tsc --noEmitとnpx vitest run works/ink-tideが通過（35テスト、nativeを含む）。
60秒のgroove → breakdown/BUILD → DROP → grooveと、3秒間隔の手動DROP2回を
24/60/120 Hzで検証する。128 BPMの各DROPで約1.88秒後にシミュレーションが再開し、
逆再生が2秒以上続かないことを確認する。
GPU呼び出しの60秒統合テストは24 Hzで実施し、描画順、読み書き競合、再シード回数も確認する。
ゼロdtの負荷試験描画、繰り返す時刻、DROP閾値の揺れ、早期DROP、
履歴の循環、80/128/180 BPM、巻き戻し、リサイズ、解放も含む。

macOSではheadless.test.tsがclangと標準OpenGLフレームワークでheadless.cをビルドする。
実際のindex.tsからシェーダー、uniform、描画・履歴コピー順を取り出し、
96 × 54のRGBA16Fで16秒・30fps（480フレーム）の経路を実行する。
0〜4秒groove、4〜10秒BUILD、10秒DROP（時定数2.2秒）、以後groove。
移流後・投影後の速度上限、染料の有限値・密度上限・壁際ゼロ、材質座標の領域内を読み戻す。
BUILD終盤の密度重心が画面内に集まること、噴流が左へ横断すること、
噴出後2秒以内に初期平均密度の30%以上へ戻り、14秒以後の可視密度領域が2%以上あることを検証する。
最終HDR出力の有限値も各フレームで確認する。追加GPUパス・ターゲット・依存はない。
macOS以外ではnativeテストはskipし、振付とGPU呼び出しのテストを実行する。
`INK_TIDE_CAPTURE_DIR=/absolute/existing/directory npx vitest run works/ink-tide/headless.test.ts`
で各秒のPPMを保存できる（ACESと簡易sRGB変換、エンジンのgrain等は含まない）。
これはWebGL/ANGLEの動作、全解像度の見た目、M5 MaxのFPS検証を代替しない。
オーケストレータはテストトラック、B長押し → Enter、calm/surgeと2ウィンドウで確認すること。

## BUILD / DROPの矩形アーティファクトと再成長

旧版は `(0.77, 0.79)` への引力に定数の上向き力を足していたため、
速度の平衡点がy≈0.98となり、染料の凝集先と一致しなかった。
さらに領域外の染料を端の画素で複製し、その密度を指数圧縮で増幅していた。
これが壁際の画素を内側へ帯状に引き延ばす経路になっていた。
移流前だけの速度制限、無制限に蓄積する材質変位も修正した。
凝集・収束・噴出の起点を統一し、壁と材質座標を全経路で制限する。
噴出後の空白は一滴への再シードに対して通常補充が毎秒約1.2%しかなく、
左への解放中はその補充まで止めていたため。新しい再成長は左の解放中も右で進む。
