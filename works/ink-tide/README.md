# INK TIDE / 墨潮

右側の三つの細い染料帯を、ゆっくり移動する渦と二層の curl-noise で曲げる作品。
細かな粒子、途切れた繊維、薄い霞を重ね、右上の濃い部分だけに暖色を添える。
指定パレットを `srgb()` で線形化し、仕上げのトーンマッピングはエンジンに任せる。

## 操作

| マクロ | 役割 |
| --- | --- |
| Energy | 粒子の明るさ。low を最大 +0.3 加算 |
| Flow | 潮の移動量と curl の強さ。往復する流れの速度も変化 |
| Density | 染料帯の幅と粒子量 |
| Detail | 繊維の細かさ。画素微分で高周波を減衰 |
| Trails | 粒子の軌跡と背景の霞 |
| Warmth | 右上の濃い部分の暖色 |
| Swirl | 三つの非対称な渦の巻き込み |
| Calm | 左側を暗く保つマスクの強さ |

`calm` は低速・疎な繊維、`surge` は流れと粒子密度を強めるプリセット。
low は潮の振幅、kick は短い染料増量と小さな流れの押し出し、high は疎な細粒の輝きを変える。
入力の音量・kick エンベロープに滑らかな応答曲線を適用する。独自の時間履歴や乱数は持たない。

## 描画と検証

流れ場は半解像度、最大 960 × 540 の HalfFloat RGBA ターゲット一枚（約 4 MiB）。
一段目に流れの変位・染料密度・暖色マスク、二段目に全解像度の粒子と線形 HDR 色を描く。
粒子は画素ごとの手続き的な表現で、大量の点ジオメトリや CPU 更新は不要。
`resize` とフレームサイズの自動追従を実装し、`dispose` で所有リソースを解放する。

フィードバック移流の代わりに、絶対時刻で評価する流線と二点の粒子露光を使用。
初回・繰り返し描画・時刻の巻き戻しで履歴による違いが出ず、別ウィンドウも同じ入力で描ける。
染料や音の過去の状態を蓄積する物理シミュレーションではない。

型チェックと6件のユニットテストでマクロ・描画順序・入力更新・リサイズ・解放を確認。
CPU 参考レンダーで構図を確認したが、WebGL の実コンパイルと Apple Silicon の FPS は未検証。
ローカルサーバー起動と GPU コンテキスト作成が実行環境で制限されているため、
エンジン統合後に 1920 × 1080・2ウィンドウでの確認が必要。
