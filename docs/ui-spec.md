# UI仕様 — Immersive

最終更新：2026-10-03 ／ 正本：デザインキャンバスの最上段（Immersive）

## 基本の考え方

- **主役はマスター映像**。画面全体に敷き、操作はすべてその上に浮かぶ黒いガラスのパネルで行う。
- **本番画面はスクロールしない**。1画面に収め、緊急ボタンは常に見える位置に置く。
- **AIの言葉は明朝**。機械の表示（等幅・ドット数字）と、AIの「声」を書体で分ける。
- **動きは拍に合わせる**。点滅やメーターの動きは BPM に同期させ、それ以外は静かに保つ。
- **本番中のAIはキュー側だけを書き換える**。客席に出ている映像には触れない。

## 色

| 役割 | 値 |
|---|---|
| 地 | `#050607` |
| ガラス | `rgba(8,10,12,.56)` ＋ `backdrop-filter: blur(16px)`、枠線 `rgba(236,230,218,.15)`、角丸 6px |
| 文字 | `#ece6da`（少し暖かい白） |
| 補助の文字 | `#a3a8a2` |
| ON AIR（`--live`） | 火 `#ff7a45`。**客席に出ている映像にだけ使う**（デッキA、放送中の作品、現在のキュー区間、Take ボタン） |
| CUE（`--cue`） | 氷 `#9fe6f2`。次に出す映像（デッキB、次のキュー、AIの書き換え先）。点線で区別 |
| アクセント（`--acc`） | 氷 `#9fe6f2`。それ以外すべて（メーター、つまみ、拍、選択中、AIの印） |
| 正常 | 苔 `#b5d38f` |
| 注意 | 琥珀 `#ffc65a` |

背景映像の上には、周辺減光と細い走査線を重ねて文字の読みやすさを確保する。

## 書体（確定）

| 役割 | 書体 | 使う場所 |
|---|---|---|
| 見出し・ロゴ | Martian Mono 200–300、横幅広め、字間 .42em | SHIKI / PERFORM、MASTER、デッキ名 |
| 数字 | Doto（丸ドット、ROND 100、太さ 800） | BPM、小節、時間、強度などの値 |
| ラベル | Martian Mono 87.5%、大文字 | パネル名、状態、単位 |
| 作品名 | Martian Mono 112.5% ／ 和名は Shippori Mincho | MOONSEA ／ 月海 |
| 和文UI | Zen Kaku Gothic New | ボタン、説明、設定項目 |

Doto は 18px 未満では使わない（ドットがつぶれるため）。

## 計器

| 計器 | デジタル要素 | 自然要素 |
|---|---|---|
| 音量メーター | セグメントが段階的に灯る | ピークの目印がゆっくり落ちる |
| 拍 | 16分の刻み | 光る丸い点、拍に合わせた明滅 |
| フレーズ | 32小節を1本ずつ並べた目盛り | 今の小節だけが呼吸するように明滅 |
| つまみ | 目盛りの粒の数で値を示す | 指標は線ではなく一粒の点 |
| クロスフェーダー | 定規の目盛り | 溝を刻んだ、指になじむつまみ |
| エネルギー履歴 | 8小節ごとの格子 | 等高線のような重なりと点描 |
| スペクトラム | 帯域ごとの棒 | なめらかな包絡線 |
| 作品のエネルギー帯 | 10個の粒 | 会場のエネルギーと重なる粒が灯る |
| テンポの揺れ（バンド） | 中心線 | 確信度を川の幅で表す |

## アクセシビリティ

- 文字のコントラストは 4.5:1 以上（24px 以上は 3:1）。ガラスの上の補助文字は `#a3a8a2` より暗くしない。
- 見分けが必要な色は、色相だけでなく明るさも変える。ON AIR（火）と CUE（氷）は色相も明るさも違い、さらに実線／点線と文字ラベルでも区別する。
- 動きは `prefers-reduced-motion` で止める。
- ストロボは上限 8Hz。光過敏への配慮として、設定で下げられるようにする。

## 素材

- `design/key-visuals/`：kv01〜kv11（作品の仮キービジュアル）。MOONSEA は kv11。
