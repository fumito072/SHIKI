## Step 1（M0）— エンジンの中核と最初の作品（2026-10-03 ほぼ完了）

- [x] 開発環境：Vite ＋ TypeScript ＋ three.js
- [x] 描画ループ、作品（楽器）の形式、共通の入力値（時間・拍・帯域・つまみ8本）、共通の仕上げ処理
- [x] 音声入力（ブラウザの音声処理はオフ）＋テスト音源、タップ／音から追従（BeatTracker：Codex 担当）
- [ ] MIDI クロック（MIDI 機器を用意してから）
- [x] コードの差し替えで落ちない仕組み（失敗したら直前の正常版を出し続ける）＋保存すると即反映
- [x] 出力ウィンドウ（操作ウィンドウと同じ状態で描画）
- [x] MOONSEA（Claude Code）と INK TIDE（Codex）をリアルタイムのシェーダーとして作成
- [x] AI が自分の作品を見られる仕組み（開発サーバー経由でフレームを保存）
- **到達点**：曲を流しながら、1作品をつまみで操作できる → 達成

## Step 2（M1）— Perform 画面の実装（目安：1〜2週間）

- Immersive の Perform 画面を実際に動くものにする
- デッキA/B とキュー、小節・フレーズ単位の切り替え、エフェクト、マクロ、MIDI learn、ライブラリ、緊急ボタン
- **到達点**：複数の作品を切り替えて DJ セットができる

## Step 3（M2）— Studio の AI 制作ループ（目安：2週間）

- 最初は Claude Code が制作役：Codex でキービジュアル候補 → 解析 → 動きの試作6案 → 楽器にする
- 人に見せる前の自動チェック：ちらつき、パレット逸脱、fps、つまみの破綻
- 版の分岐と、好みの記憶（作品ごと／全作品）
- 流れが固まったら Studio 画面と専用エージェントに置き換える

## Step 4（M3）— 共演への対応

- Electron 化
- Ableton Link、Pro DJ Link、MTC
- パート別の音（ステム）とカメラ入力
- キュー進行のフットスイッチ操作
- AI の次作品提案、本番中はキュー側だけを書き換え

## Step 5（M4）— 外部との連携と出力先の拡張

- Syphon / Spout / NDI、録画、4K 書き出し
- その後 TouchDesigner、Blender、Unity、360° 映像へ

## 毎回のやりとりの進め方

1. フィードバックをもらう（言葉、またはキャンバスへのコメント）
2. 実装し、実際に動かして確認する
3. スクリーンショットや動画で結果を見せる
4. 好みと却下した内容を記憶に残し、次の制作に効かせる
