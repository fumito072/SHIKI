# SHIKI の思想

最終更新：2026-10-03 ／ すべての作品の判断基準。磨き込みよりも優先する。

## 大目的

> 人間の脳の予測誤差の乖離をデカくして、脳をバグらせる。
> 我々の世界の中での境界線を破壊する。

脳は、見えるはずのものを予測し、網膜に入ってきた映像との誤差を手がかりにものを見ている。
その誤差が大きいほど、脳は「バグる」。SHIKI の映像は、この誤差をつくる装置である。

## 原則

1. **音に合わせて揺らすだけ、は禁止。** 振幅でピクピク反応しても、脳はすぐに予測できてしまう。
   音は「振り付け」を動かす：溜め（緊張）→ 解放、慣性のある変形、余韻。
2. **まず規則を学ばせ、それから裏切る。** 予測を育ててから壊す。いきなり壊しても誤差は小さい。
3. **物理・因果・時間の約束を破る。ただし一瞬、局所的に。** ずっと壊れていると、脳は新しい規則として予測し直してしまう。
4. **境界線を溶かす。** 図と地、内と外、実像と鏡像、液体と固体、上と下、前と後。
5. **静けさは武器。** 誤差は「静 → 急」の落差で最大になる。

## 予測誤差の装置カタログ

| 装置 | 脳の予測 | 裏切り方の例 |
|---|---|---|
| 先回り（予知） | 映像は音のあとに反応する | 拍の位置を予測できるので、拍の直前に動き出す |
| 時間の逆行 | 混ざったものは戻らない | 混ざったインクがほどけて一滴に戻る。波紋が外から中心へ集まる |
| ありえない物理 | 水は下へ落ちる | 海が月に吸い上げられる。液体が重力に逆らって糸を引く |
| 鏡像の不一致 | 反射は実物と同じ | 水面の月だけ1小節遅れて動く。光の向きが逆 |
| 図と地の反転 | どちらが物体かは決まっている | インクと水、海と空が入れ替わる |
| 運動残効 | 止まったものは止まって見える | 長い一定の流れを急に止めると、止まった絵が逆向きに流れて見える |
| 慣性のある変形 | 形はすぐ元に戻る | 液体のように伸びて曲線になり、行き過ぎてから戻る |
| スケールの曖昧さ | 大きさは一定 | マクロの雫が風景に見える（銀河の常套句は使わない） |

## 音と振り付け（エンジンが渡す信号）

| 信号 | 意味 | 使い方 |
|---|---|---|
| `kick` `onset` | 瞬間のきっかけ | 衝撃を与える。ただし反応には慣性をつける |
| `beat` `bar` `beats` | 拍と小節の位置 | 先回り（拍の直前に動き出す）、周期の組み立て |
| `tension` | 溜め：キックが消えて盛り上がる区間で上がる | 凝集、張り詰め、重力への逆らい |
| `drop` | 解放：溜めのあとにキックが戻った瞬間。手動の DROP でも発火 | 境界の破壊、反転、時間の逆行 |

## 作品への適用（2026-10-03）

- **MOONSEA**：月が海を吸い上げる「潮汐」。波紋は拍の前に中心へ集まり（逆再生）、拍で外へ広がる。
  水面の月だけが1小節遅れて動く。DROP で海と空の境界がめくれて入れ替わる。
- **INK TIDE**：本物の液体のぬめり（粘り、表面の艶、糸を引く）。キックで曲線に伸び、慣性で行き過ぎて戻る。
  溜めで一点に凝集して重力に逆らい、DROP で混ざったインクがほどけて一滴に戻り（時間の逆行）、また広がる。
